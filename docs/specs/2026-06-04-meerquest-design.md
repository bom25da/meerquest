# MeerQuest 명세 문서

MeerQuest 명세는 기획 내용과 기술 설계를 분리해 관리한다. 기획 명세는 제품 목적,
사용자, 학습 콘텐츠, UX 흐름을 정의하고, 설계 명세는 Expo 기반 React Native 앱으로
구현하기 위한 구조, 데이터, 저장소, 화면 구성 방식을 정의한다.

- [MeerQuest 설계 명세](./2026-06-04-meerquest-technical-spec.md)

## 확정된 기본 방향

- 대상 연령은 만 4~7세 미취학아동이다.
- 앱은 Expo 기반 React Native 로 개발한다.
- 스마트폰과 태블릿을 모두 지원한다.
- 앱 실행 시 MeerQuest 로고와 미어캣 캐릭터가 포함된 스플래시 화면을 제공한다.
- 미어캣 캐릭터는 땅굴에서 등장하기, 앞발 박수, 같이 고민하는 표정처럼 종 특성을
  살린 애니메이션으로 반응한다.
- 퀘스트를 완료할수록 카테고리별 난이도가 1~5단계로 올라간다.
- 첫 버전은 로컬 데이터 기반 MVP 로 시작한다.
- 서버 연동은 MVP 이후 2단계 범위로 분리한다.
